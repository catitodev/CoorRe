# CoorRe brand

Concept A. The name is written CoorRe everywhere, with that exact casing.

## What the mark says

- The open C is the limit of an agent's autonomy.
- The three verdigris dots on a line are evidence chained one step after another.
- The orange dot at the opening is the human signature, the only way past the limit.

## Tokens

| Token | Value | Use |
|---|---|---|
| ink | `#10161A` | Text on light, background on dark |
| mist | `#E9EEF0` | Background on light, text on dark |
| verdigris, light theme | `#1F7A68` | Chained evidence, pass marks, shapes |
| verdigris, dark theme | `#3FB39B` | Same, on dark backgrounds |
| signal orange | `#E8531F` | The human signature and the single MandateExceeded moment. Nothing else. |

Contrast, computed from the values above:

| Pair | Ratio | Use |
|---|---|---|
| ink on mist | 15.59 | Body text, light theme |
| mist on ink | 15.59 | Body text, dark theme |
| verdigris `#3FB39B` on ink | 7.06 | Text and shapes, dark theme |
| verdigris `#1F7A68` on mist | 4.44 | Shapes and large elements only |
| orange on ink | 4.94 | Text and shapes, dark theme |
| orange on mist | 3.16 | Large bold text (20 px) and shapes only |

Pass and fail states in the verifier are green and red, never orange.
